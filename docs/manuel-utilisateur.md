# Manuel d'utilisation — PROCOM Tools

Ce manuel s'adresse aux utilisateurs (agents) dont le compte a déjà été créé par un administrateur. Il explique comment se connecter et utiliser le **Correcteur média**.

---

## 1. Avant de commencer

Vous avez besoin de :

- votre **adresse e-mail professionnelle** (`@procom.pro`, `@agenceprocom.pro`, `@beninbouge.com` ou `@beninbouge.bj`) ;
- le **mot de passe initial** que l'administrateur vous a communiqué ;
- un **smartphone** avec l'application **Google Authenticator** (gratuite, sur Android et iOS).

---

## 2. Première connexion (à faire une seule fois)

L'accès est protégé par un double facteur : la première fois, vous devez lier votre téléphone à votre compte.

1. Ouvrez la page de connexion.
2. Saisissez votre **e-mail**.
3. Cliquez sur **« Utiliser un mot de passe »** et saisissez le **mot de passe initial**. **Laissez le champ « Code » vide.**
4. Cliquez sur **« Se connecter »**. Vous arrivez sur la page **« Activez Google Authenticator »**.
5. Sur votre téléphone, ouvrez Google Authenticator, appuyez sur **« + »**, puis **« Scanner un code QR »**, et scannez le QR code affiché à l'écran.
   - Si le scan est impossible, choisissez « Saisir une clé de configuration » et recopiez la clé affichée sous le QR code.
6. Saisissez dans le champ le **code à 6 chiffres** affiché par l'application, puis cliquez sur **« Activer et continuer »**.

Un compte « PROCOM Tools » apparaît dans Google Authenticator. L'accès aux outils est bloqué tant que cette étape n'est pas terminée.

---

## 3. Se connecter au quotidien

1. Saisissez votre **e-mail**.
2. Saisissez le **code à 6 chiffres** affiché dans Google Authenticator.
3. Cliquez sur **« Se connecter »**.

À savoir :

- Le code change **toutes les 30 secondes**. S'il est refusé, attendez le suivant.
- Un même code **ne peut servir qu'une seule fois** : si vous venez de vous connecter, attendez le code suivant pour vous reconnecter.
- Le mot de passe n'est pas nécessaire au quotidien. Si vous le saisissez (« Utiliser un mot de passe »), il doit être correct **en plus** du code.
- Après **5 tentatives échouées** en 5 minutes, la connexion est temporairement bloquée. Attendez quelques minutes.
- Pour terminer votre session, cliquez sur **« Déconnexion »** en haut à droite. Faites-le toujours sur un ordinateur partagé.

---

## 4. La page d'accueil

Après la connexion, vous voyez les **outils disponibles** sous forme de cartes. Cliquez sur une carte (ou sur **« Ouvrir l'outil »**) pour l'utiliser. Votre nom et votre rôle s'affichent en haut à droite.

---

## 5. Le Correcteur média

Le Correcteur média relit vos textes avant publication, comme un secrétaire de rédaction : orthographe, grammaire, typographie, style de la rédaction (type AFP), cohérence et points à vérifier. **Il ne réécrit pas votre texte : il le contrôle et vous indique quoi corriger.**

### 5.1 L'écran

- **À gauche** : le bouton **« + Nouvelle correction »** et votre **historique** (le plus récent en haut).
- **Au centre** : votre texte et la réponse de l'outil.
- **En bas** : la zone de saisie.

### 5.2 Faire relire un texte

1. Cliquez sur **« + Nouvelle correction »** si une ancienne correction est affichée.
2. Collez votre texte dans la zone du bas :
   - un **post** (Facebook, LinkedIn, Instagram, X) en entier : titre, corps, lien, description du partenaire, hashtags ;
   - pour un **visuel** (affiche, carrousel), collez le texte **carte par carte**, en indiquant « Carte 1 », « Carte 2 », etc.
3. Cliquez sur la flèche **➤** ou appuyez sur **Ctrl + Entrée**.
4. Patientez quelques secondes : « Relecture en cours… » s'affiche, puis la réponse apparaît.

Limite : **20 000 caractères** par texte.

### 5.3 Lire la réponse

La réponse commence par une ligne de **verdict**, par exemple :
« Verdict : publiable après corrections — 4 corrections, 1 point à vérifier (dont 1 bloquant). »

Viennent ensuite les **remarques numérotées**, classées par pastille :

| Pastille | Signification | Que faire |
|---|---|---|
| 🔴 **Erreur** | Faute d'orthographe, de grammaire, de typographie, hashtag cassé | À corriger |
| 🟠 **Style / structure** | Règle de la rédaction non respectée, lien ou appel à l'action mal placé, redondance | À corriger |
| 🔵 **Suggestion** | Amélioration facultative | À vous de juger |
| ⚠️ **À vérifier** | Fait, chiffre, nom ou information que l'outil ne peut pas confirmer | Vérifier auprès du client ou de l'équipe. Si la remarque est marquée **« bloquant »**, ne publiez pas avant confirmation |

Chaque remarque indique le texte d'origine, la correction proposée et la raison. Corrigez ensuite votre texte dans votre outil habituel.

Le bouton **« Copier »**, sous la réponse, copie toute la réponse.

### 5.4 Quelques conseils

- **Collez le texte complet**, tel qu'il sera publié : plus l'outil voit de contexte, plus la relecture est fiable.
- **Chaque correction est indépendante** : l'outil ne se souvient pas des posts précédents. Pour un texte révisé après une première relecture, collez la nouvelle version complète.
- **Vous voulez la version corrigée ?** Ajoutez une phrase en tête de votre texte, par exemple « Donne la version corrigée ». Le résultat peut varier : relisez-le attentivement.
- **L'outil peut se tromper.** Il aide à relire, il ne remplace pas votre jugement. Les points ⚠️ doivent toujours être vérifiés.
- Ne collez que des textes **destinés à être publiés**. Ne mettez pas d'informations confidentielles ou personnelles : le texte est envoyé à un service d'intelligence artificielle pour être analysé.

### 5.5 L'historique

Chaque relecture est **enregistrée automatiquement** dans l'historique à gauche. Seul **vous** voyez votre historique.

| Action | Comment faire |
|---|---|
| **Rouvrir** une correction | Cliquez sur son titre dans la liste |
| **Renommer** | Passez la souris sur l'entrée, cliquez sur **✎**, saisissez le nouveau titre |
| **Supprimer** | Passez la souris sur l'entrée, cliquez sur **✕**, puis confirmez. La suppression est définitive |
| **Modifier le texte** | Ouvrez la correction, cliquez sur **« ✎ Modifier »** sous votre texte, corrigez-le, puis **« Enregistrer et relire »**. Le texte est relu de nouveau et la **nouvelle réponse remplace l'ancienne** |
| **Nouvelle correction** | Cliquez sur **« + Nouvelle correction »** |

Le titre est créé automatiquement à partir de la première ligne de votre texte.

---

## 6. Confidentialité

Vos actions sont **enregistrées dans un journal** : connexions, ouverture des outils, corrections créées, modifiées ou supprimées (avec leur texte). Ce journal est consultable par les administrateurs et la direction. Il sert à la sécurité et au suivi de l'activité.

---

## 7. Problèmes fréquents

| Problème | Solution |
|---|---|
| **« Identifiants invalides »** | Vérifiez l'e-mail, saisissez un code **récent** à 6 chiffres. Après la première connexion, ne cochez pas le mot de passe, sauf si vous voulez l'utiliser en plus du code |
| **Le code est toujours refusé** | L'heure de votre téléphone est probablement décalée. Activez la **date et l'heure automatiques**. Dans Google Authenticator : menu ⋮ → « Correction de l'heure pour les codes » → « Synchroniser maintenant » |
| **« Ce compte est désactivé »** | Contactez un administrateur |
| **Téléphone perdu ou changé** | Contactez un administrateur : il réinitialise votre authentificateur. Vous vous reconnectez avec votre mot de passe (sans code), puis vous refaites l'étape 2 |
| **Mot de passe oublié** | Contactez un administrateur pour en obtenir un nouveau |
| **Connexion bloquée temporairement** | Trop de tentatives : attendez 5 minutes |
| **Je suis déconnecté en cours de travail** | Votre session a expiré, ou votre compte a été modifié. Reconnectez-vous |
| **Erreur pendant la relecture** | Cliquez de nouveau sur ➤. Si l'erreur persiste, prévenez un administrateur avec le message affiché |
| **« Texte trop long »** | Divisez votre texte en plusieurs parties (20 000 caractères maximum) |

---

## 8. Bonnes pratiques de sécurité

- Ne communiquez **jamais** vos codes ni votre mot de passe, même à un collègue ou à un administrateur (ils ne vous les demanderont pas).
- Gardez votre téléphone verrouillé.
- Déconnectez-vous en quittant un ordinateur partagé.
- Si vous pensez que votre accès est compromis, prévenez immédiatement un administrateur.
